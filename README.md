# PDF to Movie

PDF to Movie will transform complete text documents into engaging, lecture-like movies that combine expressive narration with relevant visual material.

The product is at the repository-scaffolding stage. The application stack and first executable product slice have not yet been selected.

## Repository map

- `AGENTS.md` — short operating map for coding agents.
- `ARCHITECTURE.md` — current system shape and architectural invariants.
- `docs/product-specs/` — product intent and acceptance boundaries.
- `docs/design-docs/` — durable engineering principles and decisions.
- `docs/exec-plans/` — active and completed implementation plans.
- `orchestration/` — Symphony workflow and operating instructions.
- `scripts/start-symphony.ps1` — project launcher for the local Symphony runtime.

## Orchestration

The project-local Symphony reference runtime is installed under the ignored `.tools/symphony/` directory. See `orchestration/README.md` for prerequisites, configuration, and startup.
